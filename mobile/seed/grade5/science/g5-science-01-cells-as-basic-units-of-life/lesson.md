# Cells as Basic Units of Life

> PAVO demo content aligned to MATATAG Quarter 1 learning goals. This is an original classroom learning aid, not official curriculum text.

## Learning goal

By the end of this lesson, you can explain **cells**, use it in a clear example, and apply the idea in a short task.

![Concept guide for Cells as Basic Units of Life](images/concept-guide.webp)

## Key idea

`cells` is the focus of this lesson. Cells carry out basic life functions and contain structures with specialized roles.

Connect the example to the key idea, then explain the connection in your own words.

## Worked example

A plant cell wall supports the cell while chloroplasts capture light energy.

Notice how the example supports the key idea instead of simply naming it. Ask: Which detail is evidence for the main idea, and how do you know?

![Worked example for Cells as Basic Units of Life](images/worked-example.webp)

## Guided practice

1. Restate the key idea in your own words.
2. Identify the important information in the worked example.
3. Complete this task: Compare labeled plant and animal cell diagrams.
4. Check your answer by returning to the definition and visual.

## Talk and think

- What detail was most useful?
- What is one common mistake someone might make?
- Where could you observe or use this idea at home, in school, or in the community?

## Remember

The goal is not only to memorize **cells**. You should be able to recognize it, explain it, and use it in a new situation.
