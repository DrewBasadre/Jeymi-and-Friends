# Changes in Matter

> PAVO demo content aligned to MATATAG Quarter 1 learning goals. This is an original classroom learning aid, not official curriculum text.

## Learning goal

By the end of this lesson, you can explain **physical change**, use it in a clear example, and apply the idea in a short task.

![Concept guide for Changes in Matter](images/concept-guide.webp)

## Key idea

`physical change` is the focus of this lesson. Heating, cooling, cutting, bending, and mixing can change matter without making a new substance.

Connect the example to the key idea, then explain the connection in your own words.

## Worked example

Ice melting changes state but remains water.

Notice how the example supports the key idea instead of simply naming it. Ask: What changed? What stayed the same?

![Worked example for Changes in Matter](images/worked-example.webp)

## Guided practice

1. Restate the key idea in your own words.
2. Identify the important information in the worked example.
3. Complete this task: Observe one reversible and one hard-to-reverse change.
4. Check your answer by returning to the definition and visual.

## Talk and think

- What detail was most useful?
- What is one common mistake someone might make?
- Where could you observe or use this idea at home, in school, or in the community?

## Remember

The goal is not only to memorize **physical change**. You should be able to recognize it, explain it, and use it in a new situation.
